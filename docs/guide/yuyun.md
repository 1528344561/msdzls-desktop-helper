# 美食雨云

云端的自定义序列, 与桌面端有不同

桌面端的 `高级功能`, 云端均支持

## Go

- 苦于退游后舍不得放弃日常奖励? 
- 不想每天惦记是否完成签到日常?
- 苦于没有Win电脑, 或者不想天天开机挂枯燥日常?

自动帮你上号签到, 无需操心落下签到奖励问题, 放心地忙你自己的事情!

支持常用操作如 `操作=签到` `操作=VIP签到`

支持运行账号数量: 2

## VIP

无需在谧境的深夜开启自己嗡嗡作响的PC烦扰自己或他人, 醒来时自动完成你的任务

```
操作=设置房间密码|密码=AABBCC
操作=设置挂机区|区=美味九区
操作=刷图|次数=1|boss=真|地图=美味悬赏|翻牌=2|最短通关时间=100秒|组队=真
操作=刷图|次数=1|boss=真|地图=火山悬赏|翻牌=2|最短通关时间=100秒|组队=真
操作=刷图|次数=1|boss=真|地图=浮空悬赏|翻牌=2|最短通关时间=100秒|组队=真
操作=刷图|次数=1|boss=真|地图=星际悬赏|翻牌=2|最短通关时间=100秒|组队=真
操作=领取悬赏
操作=刷图|次数=2|boss=真|地图=茴香竹筏（日）|翻牌=2|最短通关时间=100秒|组队=真
```

区的名字需严格与游戏内相同, 如`美味一区` `美味11区` `沙漠二区`, 密码自己设置, 尽量不要重复, 以免进入他人房间 (房间密码有长度限制, 不要设太长)

支持运行账号数量: 2

每日每个游戏账号最多支持在线 6h, 足够刷完悬赏勇士日常等一系列关卡. 超过30分钟没有操作自动下线. 定时任务执行完毕自动下线


```
操作=限制执行条件|限制=日期|允许值=26
操作=执行自定义方案|方案名称=你的方案名称
操作=自定义假期特惠兑换|数量1=25|所需物品2=星星之火|数量2=1
操作=限制结束
```
